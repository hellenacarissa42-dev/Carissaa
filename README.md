# Aplikasi Kasir PHP MySQL

## Deskripsi

Aplikasi Kasir berbasis PHP Native dan MySQL.

## Fitur

- Login Admin & Kasir
- Dashboard
- CRUD Produk
- CRUD Kategori
- CRUD User
- Upload Gambar Produk
- Keranjang Belanja
- Checkout
- Perhitungan Total
- Nominal Bayar
- Kembalian Otomatis
- Update Stok
- Riwayat Transaksi
- Struk Belanja
- Laporan Penjualan
- Cetak Laporan

## Teknologi

- PHP 8
- MySQL
- Bootstrap 5
- XAMPP
- Visual Studio Code

## Cara Menjalankan

1. Install XAMPP.
2. Aktifkan Apache dan MySQL.
3. Import database `db_kasir.sql`.
4. Salin folder project ke `htdocs`.
5. Buka:

http://localhost/kasir-app
